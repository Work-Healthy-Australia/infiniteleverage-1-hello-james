# Infinite Leverage — Brand Style Guide

Five design presets for use by the Designer agent. Each preset defines all the
parameters needed to produce consistent, on-brand visuals without further
interpretation.

---

## Preset 1 — Editorial

**Use-case:** Long-form articles, thought-leadership posts, newsletter issues, and
any content where readability and credibility are the primary goals.

**Typography**
- Heading font: Georgia (serif) — set at 32–48px, weight 700, line-height 1.2
- Body font: Inter Tight — set at 16–18px, weight 400, line-height 1.75

**Palette**
- Primary: #0B1426 (ink — main headings and key UI)
- Secondary: #2563EB (blue — links, highlights)
- Background: #F2EDE3 (cream)
- Text: #1F2A3D (ink-soft)

**Spacing scale:** 8px base — margins and padding in multiples of 8 (8, 16, 24, 32, 48, 64, 96)

**Tone:** Authoritative, measured, clear. No slang. Sentences are complete. Oxford
comma always. Short paragraphs (3–4 lines max).

---

## Preset 2 — Technical

**Use-case:** Documentation, changelogs, engineering plans, API references, and
anything where precision and scannability matter more than warmth.

**Typography**
- Heading font: Inter Tight — set at 24–36px, weight 700, line-height 1.3
- Body font: JetBrains Mono — set at 14px, weight 400, line-height 1.6

**Palette**
- Primary: #0B1426 (ink)
- Secondary: #2563EB (blue)
- Background: #FFFFFF (paper)
- Text: #64748B (gray-2)

**Spacing scale:** 4px base — tighter grid for dense information layouts (4, 8, 12, 16, 24, 32, 48)

**Tone:** Direct, functional, no marketing language. Passive voice avoided. Every
sentence earns its place. Code blocks preferred over prose for technical steps.

---

## Preset 3 — Warm

**Use-case:** Client-facing proposals, onboarding materials, welcome emails, and
content aimed at building trust with non-technical buyers.

**Typography**
- Heading font: Inter Tight — set at 28–40px, weight 600, line-height 1.3
- Body font: Inter Tight — set at 16px, weight 400, line-height 1.8

**Palette**
- Primary: #2563EB (blue)
- Secondary: #0B1426 (ink)
- Background: #F2EDE3 (cream)
- Text: #1F2A3D (ink-soft)

**Spacing scale:** 8px base — generous whitespace (16, 24, 40, 56, 80, 120)

**Tone:** Conversational but confident. First-person plural ("we"). Short sentences.
Positive framing. Avoids jargon. Ends sections with a clear next step.

---

## Preset 4 — Minimal

**Use-case:** Landing pages, hero sections, and presentations where one idea must
land instantly with zero distraction.

**Typography**
- Heading font: Inter Tight — set at 48–72px, weight 800, line-height 1.05
- Body font: Inter Tight — set at 16px, weight 400, line-height 1.6

**Palette**
- Primary: #FFFFFF (paper — on dark backgrounds)
- Secondary: #2563EB (blue — single accent only)
- Background: #0B1426 (ink)
- Text: #CBD5E1 (gray-3)

**Spacing scale:** 16px base — extreme whitespace to let the type breathe (32, 64, 96, 128, 192)

**Tone:** One claim per screen. No qualifiers. No bullet points. Headlines do all
the work — body copy is optional.

---

## Preset 5 — Bold

**Use-case:** Social media graphics, event promotions, short-form ads, and
anywhere the goal is immediate attention in a crowded feed.

**Typography**
- Heading font: Inter Tight — set at 48–96px, weight 900, line-height 1.0, uppercase
- Body font: Inter Tight — set at 14–16px, weight 500, line-height 1.4

**Palette**
- Primary: #2563EB (blue)
- Secondary: #FFFFFF (paper)
- Background: #0B1426 (ink)
- Text: #FFFFFF (paper)

**Spacing scale:** 8px base — tight but deliberate (8, 16, 24, 32, 48)

**Tone:** Punchy, declarative, action-first. Verbs lead. Three words beat thirty.
Exclamation marks used at most once per piece, and only if earned.
